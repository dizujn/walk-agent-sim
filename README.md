# 규칙 기반 보행 에이전트 시뮬레이션

서울시 행정동별 유동인구를 바탕으로, 도보 네트워크 위에 보행자 에이전트(점)를 풀어 움직임을 보여주는 Streamlit 앱입니다.

## 실행
```
pip install -r requirements.txt
streamlit run app.py
```

## 시뮬레이션 규칙
1. 1시간당 인원 = 선택 시간대 유동인구 ÷ 분기 일수 ÷ 시간대 길이(시간) → 에이전트 수
2. 실제 1초 = 시뮬레이션 1분. 보행속도도 같은 비율로 60배
3. 모든 에이전트가 0분에 선택 범위 안의 무작위 노드에서 출발
4. 노드(교차로)에서는 연결된 링크 중 하나를 동일 확률로 선택 (기본값: 왔던 길 제외, 막다른 길에서만 되돌아감)
